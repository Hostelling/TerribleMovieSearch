To start my project, I first went to the OMDb website and got my API key through the link my professor provided. From there, I created my first screen using ConstraintLayout, where I constrained my title, search bar, and search button to their respective positions. After that, I initialized three different variables: movieInput, titleText, and submitButton. Within onCreate, I set up my splash screen, which would display for 3 seconds before loading into my main screen. 
I then used findViewById to connect my variables to their respective XML elements and setOnClickListener to connect my search button to the getData() function. This function uses Volley to send a request to the OMDb API using the movie title entered by the user. 
Depending on the response, different Toast messages would appear, either confirming that a movie was found, informing the user that no movie was found, or explaining that something went wrong with the request. If a movie was found, I used optJSONArray and optJSONObject to retrieve the first movie from the search results, then used optString to get its title and poster URL.
I then used an Intent and putExtra to send that information to my second activity.

For my second activity, I created another layout containing a title, an ImageView for the movie poster, and a Back button. I used findViewById to connect the elements to my Kotlin code and getStringExtra to retrieve the title and poster URL that were passed from my first activity. 
I then displayed the title using a TextView and used Picasso to download and display the movie poster inside the ImageView. I also added two images to my drawable folder, ic_loading and ic_no_poster, which would appear while the poster was loading or if there was no poster available. I used an if statement to check whether the poster URL was null, blank, or equal to "N/A" before attempting to load it. For the Back button, I used setOnClickListener and finish() to close the second activity and return to the first screen. 
Finally, I used onSaveInstanceState to preserve the text entered into the search bar whenever the device rotated, and made it so that the splash screen would be skipped when the activity was recreated.
